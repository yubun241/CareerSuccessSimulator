# 転職成功確率シミュレーター（Career Success Simulator）

転職の「成功」を単一の指標ではなく、複数の軸（収入・人間関係・裁量権・心理的安全性 など）に分解し、各軸の達成確率からモンテカルロ・シミュレーションで確率分布を算出するインタラクティブなWebアプリです。**`index.html` 一枚だけで動作し、ビルドや依存ライブラリのインストールは不要です。**

各軸は独立ではなく「同じカテゴリの項目は連動しやすい」という前提をガウス・コピュラで表現しており、相関の強さ（ρ）をスライダーで調整しながら、確率分布がどう変化するかを直感的に確認できます。あわせて「期待していた水準」と「実際の実感」のギャップから、現在の心理的な納得度も算出します。

by 藤井工藝

## できること

- 14個の成功指標（3カテゴリ）それぞれに、一般的な達成確率(%)をスライダーで設定
- 項目のON/OFF切り替え（母集団から除外）
- カテゴリ内相関ρを0〜90%で調整し、モンテカルロ・シミュレーション（3,000試行）で分布を再計算
- 「達成軸数の確率分布」をグラフで可視化（K軸以上を達成する確率をスライダーで指定）
- 「起きやすい組み合わせ TOP5」— どの2項目が一緒に成功しやすいかを、独立仮定時との比較付きで表示
- 実際に達成した項目を「実績」ボタンでマークし、モデル上の分布の中で自分の結果が上位何%に位置するかを算出
- 各項目に「期待値」と「実感値」を入力し、その差（ギャップ）から**現在の納得度**をゲージで算出
- 「期待と現実のマップ」で、どの軸が予想以上／予想未満だったかを散布図で可視化
- 現在の全入力・算出結果を**Markdown形式のプロンプトとして書き出し**、ChatGPTやClaude等のAIにそのまま貼り付けて相談できる（用語説明付き）

## モデルの考え方

1. **各軸の確率** — ユーザーが入力する主観的な仮定値。統計データそのものではなく「自分が置いた前提」
2. **確率分布（山の形）** — その仮定を前提に、「何個の軸が達成されるか」の理論的な起こりやすさをシミュレーションしたもの
3. **相関（ρ）** — 同一カテゴリ内の項目が独立ではなく連動する度合い。ρ=0で完全独立、ρが高いほど「良い時は軒並み良い／悪い時は軒並み悪い」という現実的な挙動に近づく
4. **実績評価** — 実際の結果が、上記の分布の中でどの位置（パーセンタイル）にあるかを算出。これは「世間の実データとの比較」ではなく、**自分が設定した前提の中での相対評価**である点に注意
5. **納得度（期待×実感）** — 「達成できたか／できなかったか」の二値ではなく、各軸について「どれくらい期待していたか」と「実際どう感じたか」の差から、現在の心理的な納得度を算出。満足度は絶対的な達成量よりも期待とのギャップで決まる、という考え方に基づく

## 技術構成

- **依存ライブラリなし・ビルド不要** — `index.html` 一枚で完結する素のHTML / CSS / JavaScript
- 分布グラフ・散布図の描画も、外部チャートライブラリを使わずSVGを直接生成
- 外部API通信・サーバー処理・認証は一切なし。すべての計算はブラウザ内（ローカル）で完結するため、**利用に伴う課金は発生しません**
- 統計計算はすべて素のJavaScript実装
  - ポアソン二項分布（独立仮定時の参考値計算）
  - 標準正規分布の逆累積分布関数（Acklamの近似式）
  - ガウス・コピュラによる相関付きモンテカルロ・シミュレーション

## 使い方

ブラウザで `index.html` を直接開くだけで動作します。

GitHub Pagesで公開する場合は、リポジトリ直下に `index.html` を置いて Settings → Pages で公開ブランチを指定するだけです。ビルドステップは不要です。

```bash
git clone https://github.com/yourname/career-success-simulator.git
cd career-success-simulator
open index.html   # またはブラウザにドラッグ&ドロップ
```

ページ最下部の「現状をAI相談用プロンプト（Markdown）として書き出す」ボタンから、その時点の全入力値・算出結果・用語説明をまとめたMarkdownをコピーできます。ChatGPTやClaudeなどに貼り付けて、そのまま壁打ち相手として使えます。

## 免責事項

- 各軸の達成確率・相関係数・期待値/実感値は、いずれも入力者が置いた主観的な仮定値であり、統計的に検証された実データではありません
- 「上位◯%」等の評価は、あくまでモデル内の相対評価です。実際の転職市場の統計と一致することを保証するものではありません
- 本ツールは意思決定・心理的整理の補助を目的とした思考整理ツールであり、転職の成否や満足度を予測・保証するものではありません
